# Lab 01 - Basic LAN

## Objective

Create a basic LAN using two PCs and one Cisco 2960 switch and verify connectivity using ping.

## Topology

PC1 ---- SW1 ---- PC2

## IP Addressing

| Device | IP Address | Subnet Mask |
|--------|------------|-------------|
| PC1 | 192.168.1.10 | 255.255.255.0 |
| PC2 | 192.168.1.20 | 255.255.255.0 |

## Devices Used

- 2 × PC
- 1 × Cisco 2960 Switch
- Copper Straight-Through cables
- Cisco Packet Tracer

## Testing

From PC1:

    ping 192.168.1.20

Result: Successful

## Skills Practiced

- Basic LAN setup
- IPv4 addressing
- Subnet mask
- Cisco switch connectivity
- Ping testing
- Basic troubleshooting
